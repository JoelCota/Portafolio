# Portafolio · Joel López Cota

Sitio estático (HTML, CSS y JavaScript, sin dependencias de build).

## Estructura
- `index.html`: estructura y texto estático.
- `css/styles.css`: estilos, tokens de color y movimiento.
- `js/app.js`: datos (proyectos, experiencia, habilidades), textos ES/EN y comportamiento.

## Ver en local
Abre `index.html` en el navegador, o sirve la carpeta:

```
npx serve .
```

## Editar contenido
Los proyectos, la experiencia y las cifras viven en `js/app.js` (`PROJECTS`, `JOBS`, `FACTS`).
Cada texto tiene versión `es` y `en`.
